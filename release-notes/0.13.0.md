- The safety countdown is easier to trust. A thin bar drains along the "Keep this resolution?" row, so you see the time left at a glance. Picking the size you already have no longer starts a countdown, several picks in a row count as one trial that goes back to where you started, and Keep keeps all of them. Making a display main, or a profile that applies on its own when you dock, ends the countdown, so it never undoes what came after it.
- One Revert shortcut. The popover no longer has its own ⌘Z; set a Revert shortcut in Settings > Shortcuts and it works from any app, and the Revert row shows it once it is set.
- Your profiles are safer. One profile or display VibeRes cannot read no longer empties the whole list: the rest load, and the original file is kept next to it as `profiles-unreadable-<date>.json` before anything is saved. Changes you make with the `viberes` command line tool show up in the menu right away.
- A profile whose monitors are all unplugged is dimmed, and its tooltip says which monitor it is waiting for. The tooltip and the Apply question are now translated into every language.
- With VoiceOver, a shortcut now tells you what it did, for example which profile applied or that there was nothing to revert.
- Settings > Debug has Report a problem…, which opens a GitHub issue with your diagnostics filled in. Nothing is sent until you submit it yourself.
- Shortcut fields show when they are listening and shake when a combination is refused, and the reason goes away when you stop recording. A shortcut another app was holding starts working once that app quits.
- Launch at login shows what macOS actually does. If VibeRes is switched off in System Settings, Settings says so and offers to open System Settings.
- Smaller fixes: the hover preview glides between sizes, the display title no longer overlaps the Back button in German, refresh rates read "120 Hz" everywhere, and long dashes are gone from the text.
