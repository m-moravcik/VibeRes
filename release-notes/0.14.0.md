- New Apply Profile action in Shortcuts. Pick one of your saved profiles and it applies just like its pill or its global shortcut, then says what happened. If none of the profile's displays is connected, or every switch fails, the action fails so your Shortcut can react.
- Revert now also takes back what Shortcuts changed. Apply Profile and Set Display Resolution are remembered like a click in the popover, so Revert in the popover, or its shortcut, undoes them.
- Sizes and refresh rates look the same everywhere: the display list, both profile forms, the notes after applying, the hover preview, the "Keep this resolution?" row and Revert all write "2 560 × 1 440 · 60 Hz", in every language.
- If a saved shortcut cannot be turned on when VibeRes starts, for example because another app already uses it, the popover now shows a quiet note pointing to Settings > Shortcuts. You can dismiss it.
- Two identical monitors saved at different sizes are no longer guessed at. macOS cannot tell them apart, so VibeRes leaves them unchanged and says so, in the preview and after applying. Identical monitors saved at the same size and rate apply as before.
