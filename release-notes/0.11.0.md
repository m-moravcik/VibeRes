- Clicking a profile or a display now answers in the popover: the numbers on the changed displays roll to the new resolution, the changed card lights up, the MAIN badge moves to the new main display, and the profile's checkmark bounces as the menu bar icon plays its switch animation. With Reduce Motion on, all of it crossfades.
- Variable refresh rate (Adaptive Sync, ProMotion): VibeRes now tells variable modes from fixed ones. A display that offers both shows a separate VRR chip, Simple mode keeps a display that is on Variable on Variable, profiles remember it, and the CLI accepts `@160vrr`.
- Auto-apply now runs when a display connects, not the next time you open the menu, and a flexible "any external" profile no longer takes over a monitor that another profile names.
- A profile that moves the main display keeps the menu open, so you see what changed.
- Calmer notes: colour only on the symbol, a display that is not connected is mentioned on a quieter line instead of as an error, and notes clear when the menu closes.
- Scaled / Native and Make main display share one row, display cards keep their order when the main display moves, and long display names fit beside the MAIN badge.
- Czech, Spanish and French, so VibeRes now speaks six languages.
- Settings > Debug: an opt-in local debug log and Copy diagnostics for bug reports. VibeRes still sends nothing anywhere, and display names are never written to the log.
- Fixed: the MAIN badge could stay on the display that had lost the menu bar, and the laptop symbol followed the main display instead of the built-in one.
