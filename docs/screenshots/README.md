# Screenshots

These are the captures the root [README](../../README.md) embeds. They are
real, current, and named with a version suffix so a refresh does not silently
replace a picture the README still describes in the old terms.

| File | Shows |
|---|---|
| `icon.png` | App icon, used as the README header |
| `root-v2.png` | Root popover: profile pills and display cards |
| `detail-v2.png` | Per-display detail: current-mode card, Scaled/Native toggle, size rows |
| `save-v2.png` | Inline "Save profile" form with per-display checkboxes |

## Retaking one

1. Open VibeRes and navigate to the screen you want.
2. `⌘⇧4`, then `Space`, then click the popover window.
3. Save over the existing file, or bump the suffix (`-v3`) and update the
   `<img>` tags in the root README so the two cannot drift apart.

Keep the popover at its natural width — do not resize the window before
capturing, or the proportions stop matching what a reader sees.
